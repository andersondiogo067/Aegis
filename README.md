# Aegis Browser

A personal Chromium patch stack focused on strong privacy defaults and an optional Tor-backed Anonymous mode.

Status: development scaffold. This repository does not claim that a Chromium binary has been built on the current host. See `docs/BUILD.md` and `docs/ENVIRONMENT.md`.

Security invariants: Chromium sandbox, Site Isolation, TLS certificate validation, process separation, and timely upstream security updates remain enabled.
